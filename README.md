# DI Next

An agentic, natural-language and voice-enabled uplift of Kinective Data Intelligence: a working demo built local-first in slices, with every institution, person and figure synthetic.

- [`app/`](app/README.md): the code, how to run it, and what each slice added
- [`app/deploy/azure/`](app/deploy/azure/README.md): deploying the demo to Azure from Cloud Shell

The product specification, backlog and feature inventory the code refers to (for example "spec 8.24") are kept outside this repository.
